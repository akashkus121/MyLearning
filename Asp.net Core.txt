Static File Serving (UseStaticFiles): This option enables the serving of static files (e.g., CSS, JavaScript, images) from the wwwroot directory or any specified directory.
Default File Serving (UseDefaultFiles): Configures a default file (e.g., index.html, default.html) to be displayed when the user accesses the root URL of a directory.

Directory Browsing (UseDirectoryBrowser): Enables the option for users to view the directory contents in the browser (e.g., see the files in a folder if no default file is present).

Temp Table---A temp table is a temporary table used to store data temporarily for the session or transaction. There are two types:

Local temp table: Exists only during the session in which it was created (e.g., #TempTable).ex - create #User(Id int identity(1,1),Name Varchar(20));
Global temp table: Visible to all sessions and users (e.g., ##TempTable).

Tracking vs NoTracking in EF Core (VERY IMPORTANT)
Tracking-when EF fetch the data it keep the record , and if any change happen happen it automatically update the change. Generally used for -update , deleted, insert.
ex- {
var user=_context.Users.FirstorDefault(x=>x.id==1)
user.Name="Akash"
_context.Savechanges();
}
NoTracking- it does not track the record of data , mainly for reading it is faster because does not use any memory.
you can update here alos but need to manage it manually. by using _context.Users.Update(user)
ex= var user=_context.Users.AsNoTracking.FirstOrDefault(x=>x.id==1)
